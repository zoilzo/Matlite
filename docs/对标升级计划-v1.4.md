# 🧭 MatLite 对标主流软件升级计划（v1.4 起）

> 生成时间：2026-09-21 · 版本：v1.3.0 之后的路线图
> 目的：对标 MATLAB / Mathematica / Origin / Prism / SPSS / Jupyter / GeoGebra / Desmos / RStudio / Jamovi，制定可执行的升级路线。

---

## 一、MatLite 现状定位

**一句话**：免费 · 本地 · 数据不上传 · 全中文 · 面向不会代码的中国大学生——这是市面上**没有直接对标**的组合。

已具备：15 个功能模块、41 个 AI 工具、拍照识题、Word 报告、历史记录、公式 LaTeX 渲染。

**与商业软件的核心差距**（按学生影响排序）：

| 差距 | 对标 | 现状 |
|------|------|------|
| 绘图质量（出版级模板/矢量导出） | Origin | 10 类基础图，仅 PNG |
| 统计检验向导（该用哪个检验） | Prism/JASP | 用户自己选，无推荐 |
| 即时反馈（滑杆动画/输入即出图） | GeoGebra/Desmos | 无交互控件 |
| 统计检验家族完整性 | SPSS | 缺非参/多重比较/逻辑回归等 |
| 报告完整性（全检验进 Word/PDF） | SPSS/Prism | 仅 desc/t/回归 可进报告 |
| 可复现工作流（实时脚本） | MATLAB/Jupyter | 无 |
| 数据导入格式 | SPSS/Origin | 仅 xlsx/xls/csv |

**差异化护城河**（继续做强）：AI 自然语言助手（对标 Wolfram Alpha）、拍照识题 OCR、本地免费中文一体机。

## 二、升级路线图（按版本规划）

### 🟢 v1.4.0 —— 统计先行（对标 SPSS/Jamovi/Prism）

> 学生论文/作业刚需，scipy/statsmodels 有现成实现，工作量可控。

**P0 统计检验补齐**
- 非参数检验独立入口：Mann-Whitney U、Wilcoxon 符号秩、**Kruskal-Wallis**（ANOVA 非参替代）、Friedman（重复测量）
- **事后多重比较**：Tukey HSD / LSD / Bonferroni（ANOVA 显著后学生必问"哪两组不同"）
- 效应量扩展：ω²、偏 η²、Cohen's f（论文规范要求）
- 单样本 t 检验、比例检验（二项）、McNemar（配对卡方）
- 逻辑回归（二分类，论文常用）
- 多元线性回归（含 VIF 共线性、Durbin-Watson）
- 信度分析 Cronbach's α（问卷分析必备）

**P1 数据导入扩展**
- txt / json 格式、拖拽导入
- 数据清洗向导：缺失值策略、标准化/对数变换、异常值剔除

**配套**
- 统计分析结果表统一输出"效应量 + 中文结论一句话"
- AI 工具同步新增上述检验（保持 41 → 50+ 工具）

### 🟢 v1.5.0 —— 绘图与报告（对标 Origin/Prism/R Markdown）

**P0 出版级绘图**
- **模板/主题系统**：存图样式为模板复用（配色、坐标轴、图例）
- 新图类型：小提琴图、箱线图、误差棒图、饼图、密度图、热力图（相关矩阵）
- **矢量导出**：SVG / PDF / EMF + 复制图到剪贴板（clipboard_util 已存在未接线）
- 图例/坐标轴/标题细节面板

**P1 Word 报告全覆盖**
- 卡方 / ANOVA / 相关性 / 配对 t 结果进入 Word 报告
- **APA 三线表**格式 + 图表标题图注自动生成
- 报告模板选择 + 封面/目录
- PDF 导出（python-docx → docx2pdf）

### 🟢 v1.6.0 —— 交互与数据科学（对标 GeoGebra/Jupyter/MATLAB）

**P0 交互可视化**
- **滑杆调参实时出图**：函数曲线/分布/曲面参数滑杆（GeoGebra 式）
- 输入即出图（减少点击，Desmos 式即时反馈）
- 3D 交互旋转（mpl_toolkits 原生支持）

**P1 数据科学补强**
- 分布库扩展：t、χ²、F、β、γ、韦布尔、几何、超几何（统计学本科全用到）
- 时序：ADF/KPSS 平稳性检验、SARIMA、自动定阶、预测精度（MAPE/RMSE）、Ljung-Box 白噪声
- ML：逻辑回归、随机森林、SVM、kNN、PCA 降维、ROC/混淆矩阵、交叉验证

### 🟢 v1.7.0 —— AI 增强（差异化高峰）

- **多模型协作**：本地 Ollama + 云端 DeepSeek/GPT 分工（本地算工具、云端讲思路）
- 对话持久化 / 导出、上下文长度管理、停止生成按钮
- AI 自动讲解"为什么"（结合统计结果做方法选择解释）
- OpenAI 兼容模式的 function calling
- OCR 批处理（多题识别）、拍照入口、错题本

### 🟢 v1.8.0 —— 深度计算（对标 MATLAB/Mathematica）

- 矩阵分解：LU/QR/SVD/Cholesky、行阶梯形、条件数、大矩阵数值算法
- 计算器：高阶导、级数展开、化简/因式分解、方程组 UI、变量定义复用
- 数值：ODE 数值解（RK4/solve_ivp）、插值、FFT、非线性优化
- 微积分：方向场/斜率场、傅里叶级数、偏导/梯度/多重积分
- 复变：任意奇点留数、洛朗展开、围线积分、共形映射
- 可复现工作流：操作历史一键重跑、会话保存（轻量 Live Editor）

## 四、实施建议

1. **先做 v1.4.0**（统计）：学生论文刚需 + 实现成本低（scipy/statsmodels 现成）+ 与 AI 工具联动价值高
2. **统计向导化**贯穿始终：每一步统计输出"该检验是否合适 + 结论怎么读"中文解释（对标 Prism/JASP 结果解释）
3. **保持 AI 助手同步**：每个新统计/绘图功能都暴露为 AI 工具，让 AI 助手成为"自然语言入口"
4. **每个版本保持**：全链路版本同步（bump_version）+ py_compile + GUI 构建测试 + 打包发布
