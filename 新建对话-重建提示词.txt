================ MatLite 新对话重建提示词 ================

【项目】
MatLite 数学工作台 —— MATLAB 风格的本地桌面数学/统计工具。
技术栈: Python + customtkinter + matplotlib + numpy + pandas + scipy + sympy + sklearn + statsmodels + python-docx + openpyxl + requests。
项目路径: C:\Users\19627\Desktop\MatLite
环境: Windows 11，Git Bash，Python 3.10.6。

【应用结构】
app.py 里注册 15 个页面（都在 modules/ 目录）：
CalculatorPage(公式计算) MatrixPage(矩阵) NumericPage(方程数值)
CalculusPage(微积分深化) ComplexPage(复变函数) ProbPage(概率分布)
PlotPage(绘图可视化) DataPage(数据分析) TimeSeriesPage(时间序列)
MlPage(机器学习) AiPage(AI助手) OcrPage(拍照识题)
HistoryPage(历史) SettingsPage(设置) HelpPage(帮助)。
每个页面沿用“左侧参数面板 + 右侧结果/画布”，matplotlib 画布用独立 box 子框架 + pack（box 再 grid 到右框架）。

【重要：上一会话的字面量生成异常】
写作含数字的代码时，数字会被随机改写（如 160 变 763），导致设置/反馈/矩阵三个文件布局错乱。
因此新对话务必：
  * 布局用 pack / 行计数器变量(r += 1) / len(key) 派生的值，尽量少手写多位数字；
  * 每改一个文件都 py_compile + 打开 GUI 构建测试确认；
  * 用户的正式要求：意见反馈恢复到第一版 v1.0.0 的 SMTP 直发样式；设置页所有设置都要可见；矩阵预览不要数字与边框重叠。
