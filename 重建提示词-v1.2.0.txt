================ MatLite 新对话重建提示词（v1.2.0） ================

【项目】
MatLite 数学工作台 —— MATLAB 风格的本地桌面数学/统计工具。
技术栈: Python + customtkinter + matplotlib + numpy + pandas + scipy + sympy + scikit-learn + statsmodels + python-docx + openpyxl + requests + PIL。
项目路径: C:\Users\19627\Desktop\MatLite
环境: Windows 11，Git Bash，Python 3.10.6。

【当前版本】v1.2.0（已打包到 releases\v1.2.0\）

【应用结构】
app.py 注册 15 个页面（modules/ 目录）：
Calculator(公式) Matrix(矩阵) Numeric(数值) Calculus(微积分深化)
Complex(复变函数) Prob(概率) Plot(绘图) Data(数据分析)
TimeSeries(时序) Ml(机器学习) Ai(AI助手) Ocr(拍照识题)
History(历史) Settings(设置) Help(帮助)。

每页沿用「左侧参数面板 + 右侧结果/画布」，matplotlib 画布用独立 box 子框架 + pack。
根目录有 3 个统计文件: stats_utils.py / stats_plots.py / stats_report.py（非 modules/）。

【重要：避数字污染】
上一上一会话写含数字的代码时数字会被随机改写（如 160→763），因此：
  * GUI 布局用 pack / 行计数器变量（r += 1）/ len() 派生值
  * 每改一个文件都 py_compile + 打开 GUI 构建测试
  * ai_tools 里算法数字无妨（不是布局数字）
